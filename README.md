Setup using pelican with flex theme.

This blog helped

https://shahayush.com/2020/03/web-pelican-pt3-hosting/

## Publish

```bash
# assume source branch has been commited and pushed
ghp-import output -b gh-pages # create content for the gh-pages branch
git push origin gh-pages # push local to remote gh-pages branch
```

- [Pelican](https://docs.getpelican.com/en/stable/)
- [Flex - pelican theme](https://flex.alxd.me/)
